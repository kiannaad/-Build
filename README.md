## 同步规则

- 仓库只放脱敏内容；`Memory/`、`Journal/`、`Inbox/`、`Media/`、凭据默认被 `.gitignore` 排除。
- 如果要同步记忆或日报，先把仓库改为 **private**，再逐项确认。
- 插件不进仓库；换机时按重建文档的插件清单重装。
