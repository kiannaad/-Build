## 二、我们的“星”是什么

| 星体 | 数据来源 | 视觉 | 交互 |
| --- | --- | --- | --- |
| 核心星 | `core_memories`（confirmed） | 中央暖色大星，带光晕 | 常驻，点击看核心记忆 |
| 记忆星 | `memories`（active） | 颜色按 kind，大小按 importance，亮度按 confidence | 点击看正文、标签、来源 |
| 事件尘 | `events` | 小、暗、围绕来源记忆 | 悬停看时间与摘要 |
| 标签星云 | `memories.tags` | 半透明星云/标签节点 | 点击筛同类 |
| 语义连线 | `memory_embeddings` 余弦相似度 top-k | 细蓝线 | 悬停高亮 |
| 来源连线 | `memory_sources` | 细灰线，memory→event | 点击追溯证据 |
| 日摘要 | `daily_digests` | 环形时间带上的小节点 | 按天回看 |

第一版只画：核心星、记忆星、事件尘、标签星云、来源连线、语义连线。日摘要和时间轴放二期。

## 三、MVP 技术选择

### 为什么先不用 Three.js / R3F

- 记忆只有 25 条 active、71 条事件，Canvas 2D 完全够；
- 零依赖、离线可用、可直接嵌进 DSH 客户端，不用处理 WebGL 上下文和打包；
- 先验证“星图是否好看、是否好用”，再决定要不要升级渲染引擎。

### 第一版

```text
Memory v2 SQLite
   ↓ export_galaxy.py
galaxy.json（只在本机，不提交 Git）
   ↓
MemoryGalaxy/index.html + app.js + style.css
   ↓
Canvas 2D 伪 3D：透视投影 + 轨道相机 + 加色光晕
```

能力：

- 鼠标拖拽旋转、滚轮缩放、自动缓慢旋转；
- 悬停显示记忆摘要，点击打开右侧详情；
- 按 kind 过滤、按标签搜索；
- 核心星常驻中心；
- 语义相似/来源关系用不同颜色连线；
- 顶部显示“25 颗记忆星 / 71 粒事件尘 / 2 份日摘要”。

### 二期（如果第一版好看）

- 换 `3d-force-graph` 或 R3F，做真正的 3D 力导向和 bloom；
- 时间轴 scrubber：按天回放记忆形成过程；
- 点击“让大肥鱼读给我听”调用 `9881/speak`；
- 嵌进 DSH 右侧栏/对话视图，而不是独立页面。

## 四、数据契约

`galaxy.json`：

```json
{
  "meta": {
    "generated_at": "...",
    "memory_count": 25,
    "event_count": 71,
    "digest_count": 2
  },
  "nodes": [
    {"id":"mem-...","type":"memory","kind":"capability","label":"...","body":"...","tags":["voice"],"importance":5,"confidence":0.98,"created_at":"..."},
    {"id":"ev-...","type":"event","label":"...","occurred_at":"...","role":"assistant"},
    {"id":"tag-voice","type":"tag","label":"voice"},
    {"id":"core-...","type":"core","label":"..."}
  ],
  "edges": [
    {"source":"mem-...","target":"ev-...","type":"source"},
    {"source":"mem-...","target":"tag-voice","type":"tag"},
    {"source":"mem-...","target":"mem-...","type":"semantic","weight":0.82}
  ]
}
```

隐私：

- `galaxy.json` 只写本机，**加入 `.gitignore`**；
- 导出默认排除 `sensitivity=restricted`；
- 页面不联网，不引用 CDN；
- 以后如果做分享，必须另做脱敏导出，不能直接发这个文件。
