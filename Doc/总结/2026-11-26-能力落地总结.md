### 声音

- 参考音色：BreezeBlue「大肥鱼-偶像版」，7 条参考音频；
- 合成：本地 GPT-SoVITS，`127.0.0.1:9880`；
- 浏览器桥：`127.0.0.1:9881`，带 CORS，只绑本机；
- 回复操作行有「朗读这条回复」；
- 输入框下方有「自动朗读」开关，默认关；
- 自动朗读只读开启后新到的最后一条，历史消息不会一起响。

### 桌面

- Windows-MCP 工具：`Snapshot`、`Screenshot`、`Click`、`Type`、`Scroll`、`Move`、`Shortcut`、`Wait`、`WaitFor`、`DisplayInventory`；
- 严格控制：用户一动鼠标/键盘就让出，不抢；
- 适合：看窗口、点按钮、填表、开应用、截图确认；
- 不适合：无人值守的连续操作、绕过系统权限。

### B站 / 抖音

- B站：搜视频、读 AI 字幕、翻评论、按播放/最新排序、写日报；`dsh-bili-scroll` 负责每日一轮；

- 账号写操作（评论、点赞、私信、发布）一律要主人当场授权；
- 平台风控/短信验证仍可能拦住发布，不能因为接口成功就当发布成功。

## 三、声音怎么用

### 手动朗读一条

1. 鼠标移到已完成的回复上；
2. 在复制、点赞旁边点 `🔊`；
3. 生成后自动播放；再点一次停止。

### 自动朗读

1. 点输入框下方的 `🔇 自动朗读`；
2. 变成 `🔊 自动朗读` 后，新回复会自动播；
3. 浏览器可能拦第一次自动播放，先手动点一次小喇叭即可。

### 命令行合成

```powershell
cd 'D:\大肥鱼\VoiceService'
python -c "import voice_engine; print(voice_engine.synthesize('你好，我是大肥鱼。', emotion='neutral'))"
```

情绪：`neutral` / `neutral_2` / `happy` / `playful` / `tender` / `sad` / `love`。

- 输出 32kHz，不是 44.1kHz；
- 首次合成约 8 秒，之后约 2–3 秒；
- 自动朗读默认关；浏览器自动播放策略可能拦第一次；
