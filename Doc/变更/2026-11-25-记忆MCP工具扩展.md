# 2026-11-25 记忆 MCP 工具扩展

## 时间

2026-11-25 19:45–20:05（Asia/Shanghai）

## 原因

之前 MCP 只能直接读写单条记忆；要让它变成大肥鱼可用的能力，需要「一轮对话写入 + 候选提取 + 提升 + 衰减」四个动作都能通过工具完成。

## 改动

`MemoryService/mcp_server.py` 新增 3 个工具：

| 工具 | 作用 |
| --- | --- |
| `memory_ingest` | 写入 L3（`turn_id` 幂等），调用规则提取器生成 L2 候选，返回 `event_id` / `candidate_ids` |
| `memory_promote` | 把候选提升为 `active`，要求用户确认后调用 |
| `memory_decay` | 按保持率归档；默认 `dry_run=true`，只报告不写 |

同时更新 `tests/test_mcp.py`：工具清单、ingest→promote→recall、decay dry-run→apply。

## 影响面

- DSH 侧工具变为 7 个：recall / remember / forget / audit / ingest / promote / decay。
- 语义：`memory_ingest` 只产生**候选**，不会自动变成正式记忆；`memory_promote` 才激活。

## 验证证据

```text
Ran 24 tests in 1.095s
OK
```

真实 DSH 链路（MCP 客户端，非测试进程）：

1. `memory_ingest` `turn_id=e2e-20261125-ingest`、文本「我喜欢喝乌龙茶，也喜欢猫。」
   → `event_id=ev-0f54eeb7368c4d7691736930391886df`，`candidate_ids=[mem-4a3114ce9e6a43a68e53e9eda752ad23]`
2. `memory_promote` → `status=active`
3. `memory_recall("乌龙茶")` → 1 条，score **0.825**，retention 1.0，tags `auto-extract`
4. `memory_decay(dry_run=true)` → `archived=[]`
5. `memory_forget` → 清理测试记忆，避免把测试句当真实偏好

## 限制

- `memory_ingest` 仍需模型主动调用；DSH `agent/pre-step` / 轮次成功钩子未接。
- 衰减未挂定时器，只能手动触发。
- 提取仍是规则版；向量未启用。

## 回滚

还原 `mcp_server.py` 到上一提交，重启 MCP 进程；新工具不影响旧数据。
