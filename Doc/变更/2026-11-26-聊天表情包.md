# 2026-11-26 聊天表情包

## 原因

主人要求聊天里能嵌入大肥鱼表情包，而不是只能发文字。

## 素材

新增 `D:\大肥鱼\Stickers`：

- 使用 `dsh-pet` 自带的 `assets/memes`，本地复制到 `Stickers/pet/`；
- 25 张 PNG，384×384，保留原文件名映射到 ASCII 别名；
- `manifest.json` 记录别名与来源；
- `MemoryGalaxy/Stickers` 目录联接指向它，由 9882 静态服务提供 `/Stickers/<name>.png`。

## 协议

模型决定要不要发，单独一行写：

```markdown
[dfy-sticker-1]: # "comfort"
```

这是 Markdown 链接引用定义，渲染不可见；`VoicePlugin` 新增 `StickerTurnBubbles`，在 `conversation.chat.turnTail` 解析并渲染 140px 图片。一次最多两张，不替代文字。

## 验证

- `GET http://127.0.0.1:9882/Stickers/pet/cute.png` 返回 200，166,125 bytes；
- 插件语法通过；
- 客户端需要刷新 DSH 页面加载新组件；
- 真实聊天里的图片渲染待刷新后验收。

## 限制

- 依赖 9882 页面服务；`start-all.ps1` 会一起拉起；
- 模型漏写标记就不发图；
- 图片只从固定白名单选择，不接收任意路径；dsh-pet 素材只在本机使用，不提交公开仓库。
