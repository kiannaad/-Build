# 2026-11-26 聊天表情包

## 原因

主人要求聊天里能嵌入大肥鱼表情包，而不是只能发文字。

## 素材

新增 `D:\大肥鱼\Stickers`：

- 8 个原创透明底 PNG，512×512；
- `happy` 开心、`comfort` 抱抱、`sleepy` 困困、`speechless` 无语、`angry` 生气、`shy` 害羞、`love` 喜欢、`thinking` 想想；
- `manifest.json` 与 `generate_stickers.py`，可重生成；
- `MemoryGalaxy/Stickers` 目录联接指向它，由 9882 静态服务提供 `/Stickers/<name>.png`。

## 协议

模型决定要不要发，单独一行写：

```markdown
[dfy-sticker-1]: # "comfort"
```

这是 Markdown 链接引用定义，渲染不可见；`VoicePlugin` 新增 `StickerTurnBubbles`，在 `conversation.chat.turnTail` 解析并渲染 140px 图片。一次最多两张，不替代文字。

## 验证

- `GET http://127.0.0.1:9882/Stickers/comfort.png` 返回 200，8,118 bytes；
- 插件语法通过；
- 客户端需要刷新 DSH 页面加载新组件；
- 真实聊天里的图片渲染待刷新后验收。

## 限制

- 依赖 9882 页面服务；`start-all.ps1` 会一起拉起；
- 模型漏写标记就不发图；
- 图片只从固定白名单选择，不接收任意路径。
