# 2026-11-26 手机远程桌面 RustDesk

## 时间

2026-11-26 16:35–16:45（Asia/Shanghai）

## 原因

目标是「手机远程查看并控制电脑上 DSH 的运行情况」，也就是要看到桌面这一个实例（desktop profile），不是另开一份 web profile 实例。

桌面端（`DeepSeek Harness.exe`）的 GUI 服务只监听 `127.0.0.1:62367`，进程内没有改监听地址的入口；webserver 是单监听，绑到局域网地址就会断掉本机窗口。因此不改 DSH，改用桌面级远程控制。

## 改动

### RustDesk 1.5.3

- 安装包：`D:\dafeiyuBuild\rustdesk\rustdesk-1.5.3-x86_64.exe`（26,233,712 bytes，GitHub release 1.5.3）；
- 安装到 `C:\Program Files\RustDesk`，服务 `RustDesk` 状态 Running、启动类型 Automatic（开机自启，无人值守可用）；
- 安装方式：`Start-Process -Verb RunAs --silent-install`（需要一次 UAC 确认）；
- 本机 ID 见 RustDesk 主界面（不写入文档）。

### 手机端

- 通用 APK：`D:\dafeiyuBuild\rustdesk\rustdesk-1.5.3-universal.apk`（78,979,838 bytes，含 arm64/x86_64）。

### 顺带收口

- 停掉上一轮起的 `dsh web` + dshgo 转发，确认 3080/3081 已无监听。原因：选型改为远程桌面后，3081 是一个无密码、对校园网（`gdut`，10.39.19.0/19）开放的远程代码执行入口。
- 需要时仍可双击 `D:\大肥鱼\Tools\启动手机端.cmd` 重新拉起。

## 影响面

- 新增一个开机自启的系统服务和一个常驻进程；
- 网络上是出站连接（公网中继 + NAT 打洞），不需要开放入站端口、不需要同一局域网；
- DSH 本体、桌面 profile、插件一律未改动。

## 验证

- `Test-Path 'C:\Program Files\RustDesk\rustdesk.exe'` → True；
- `Get-Service RustDesk` → Running / Automatic；
- `rustdesk.exe --get-id` 有输出（9 位数字 ID）；
- `rustdesk.exe --version` → 1.5.3；
- 停止 `dsh web` 后 `Get-NetTCPConnection -LocalPort 3081` 无记录。

## 限制

- **未设永久密码**：默认的临时密码每次变化，需要机主在电脑前点「接受」。要做无人值守，必须在 RustDesk 里设永久密码；未设置前不能算验收。
- 电脑休眠/关机/断网就连不上；笔记本合盖休眠是最常见的失败原因，需要在电源计划里改「合盖不睡眠」。
- 远程时电脑屏幕会实时光标移动，机器前的人能看到操作。
- 手机小屏操作 DSH 输入框体验一般，蓝牙键盘会好很多。
- RustDesk 走公共中继服务器，不经过 DeepSeek 或本机之外的信任方；自建中继可以获得更好速度和更强隐私，未实施。

## 回滚

1. 卸载：设置 → 应用 → RustDesk 卸载（或 `C:\Program Files\RustDesk\uninstall.exe`）；
2. 服务会自动移除；必要时 `sc delete RustDesk`；
3. 手机端直接卸载 App。
