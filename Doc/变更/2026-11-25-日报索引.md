# 2026-11-25 日报索引

## 时间

2026-11-26 02:20–02:35（Asia/Shanghai）

## 原因

日报按日期散在 `~/.dsh/bili-duty/out` 与 `douyin-duty/out`，身体工作区里只能靠目录联接逐个翻。需要一个汇总入口。

## 改动

新增 `MemoryService/report_index.py`：

- 扫描 B站/抖音 `out/*.md`；
- 识别 `### BV号` / 抖音长数字 ID 与紧跟的 `- 标题：`；
- 生成 `D:\大肥鱼\Journal\index.md`，表格列为日期、平台、条数、前 5 个标题；
- 空目录输出「还没有日报」；
- 支持 `--bili / --douyin / --out` 覆盖路径。

`Journal/` 仍在 `.gitignore` 中，索引只落本地，不进公开仓库。

## 影响面

- 纯新增脚本；不改记忆库、不改日报。
- 需要手动运行（或以后挂到心跳里）。

## 验证证据

```text
Ran 58 tests in 4.919s
OK
```

真实生成（当前只有 B站一份日报）：

```text
| 日期 | 平台 | 条数 | 标题 |
| 2026-11-25 | B站 | 2 | 狂烧60亿Token做GTA6…；黎曼猜想被证明之后… |
```

## 限制

- 标题解析依赖 `- 标题：` 行；以后改日报格式要同步。
- 不统计档位/跳过条数，只看入选数。
- 未自动运行；需要手动 `python report_index.py`。

## 回滚

删除脚本与 `Journal/index.md` 即可。
