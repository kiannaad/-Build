# 2026-11-25 日报接入每日摘要

## 时间

2026-11-26 03:00–03:15（Asia/Shanghai）

## 原因

日报落在 `Journal/`，但记忆的 L1 摘要不知道今天推荐了什么；问「今天有什么值得看的」时，摘要里只有消息计数，没有内容。

## 改动

`MemoryService/digest.py` 的 `generate()` 增加日报概览：

- 读 `~/.dsh/bili-duty/out/<day>.md` 与 `douyin-duty/out/<day>.md`；
- 只认严格 `YYYY-MM-DD.md`，跳过 `forward-*.md`；
- 解析 `### BV号/数字ID` 后的标题（B站 `- 标题：`、抖音 `**标题** ·`）；
- 摘要追加「日报：B站推荐 N 条（前 3 个标题）；抖音推荐 M 条（…）。」；
- `report_dirs` 参数可注入，便于测试。

## 影响面

- L1 摘要变长（最多约 200 字），但信息更有用；
- 不改召回/记忆卡，不影响日报文件；
- 心跳刷新摘要时会自动带上当天日报。

## 验证证据

```text
Ran 59 tests in 5.122s
OK
```

真实摘要（2026-11-25）：

```text
用户 13 条、助手 3 条消息（2 个会话）；新增候选 0，激活 1。
日报：B站推荐 2 条（狂烧60亿Token做GTA6…；黎曼猜想…）；
      抖音推荐 3 条（大狗狗（动画）；「记住这个 ID…」；星星之火，可以燎原（二创））。
```

## 限制

- 只取前 3 个标题，后面的不展开；
- 标题解析依赖日报格式，模板改动要同步；
- 摘要不判断推荐质量，只做索引。

## 回滚

还原 `digest.py` 与测试；已生成的摘要不会被自动改回，需要重新 `memory_digest_generate`。
