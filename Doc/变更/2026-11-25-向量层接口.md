# 2026-11-25 向量层接口

## 时间

2026-11-25 21:00–21:20（Asia/Shanghai）

## 原因

`memory_embeddings` 表一直空着，召回只能靠关键词。本地 Ollama 没有嵌入模型，也不该为了测试强行拉 1GB 模型；先把向量层做成可插拔接口，模型到位即可启用。

## 改动

1. `MemoryService/embeddings.py`
   - `Embedder` 协议 + 两个后端：`OllamaEmbedder`（`/api/embed`，默认 bge-m3）、`SiliconFlowEmbedder`（OpenAI 兼容，key 只读 `SILICONFLOW_API_KEY`）。
   - `pack/unpack`（float32）、`cosine`。
   - `save_embedding` / `load_embeddings`：按模型隔离，保存维度与内容哈希。
   - `embed_missing`：只给 `active` / `candidate` 且**非 restricted** 的记忆补向量。
   - `semantic_candidates`：对 active 记忆暴力余弦，过滤 restricted。
2. `tests/test_embeddings.py`（5 项，用假 3 维嵌入器，不联网）。

## 影响面

- 纯新增模块；未接入 `recall`，未改 MCP 工具。
- 数据库新增 `memory_embeddings` 行（测试库）；真实库仍为空。
- `restricted` 不会被发送给嵌入服务（符合隐私设计）。

覆盖：pack/unpack 往返、cosine、补向量幂等、语义最近邻、restricted 无向量、模型隔离。

## 限制

- 没有可用模型：Ollama 列表为空，`SILICONFLOW_API_KEY` 未配置，所以真实语义召回还没跑过。
- 召回主路径仍是 FTS/LIKE；向量只做到「候选 → 相似度」这一层。
- 数据量大时需要换 `sqlite-vec`，当前是 Python 暴力余弦。
