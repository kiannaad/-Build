# 2026-11-25 模型提取骨架

## 时间

2026-11-26 01:30–01:45（Asia/Shanghai）

## 原因

规则提取只认显式线索（喜欢/我养了/记住…），隐含偏好会漏。设计里模型提取是「后续可选层」；先把接口、解析与校验做好，用假模型测试，等接入本地 chat 模型即可启用。

## 改动

`MemoryService/llm_extractor.py`：

- `extract_with_model(conn, event_id, call_model)`：调用方注入 `call_model(prompt) -> str`，可接 Ollama / 任意 API；
- 系统提示：只提取用户明确表达的事实/偏好/关系/承诺/边界/经历/兴趣；不提取寒暄与临时任务；不编造；敏感内容跳过；最多 5 条；只返回 JSON；
- 解析容错：支持纯 JSON、`{"memories":[...]}`、```json 围栏；坏 JSON 返回空；
- 校验：kind 白名单、body ≤200 字、重要度 1–5、置信度 0–1、敏感词跳过；
- 只写 `candidate`，`tags=model-extract`，必须引用来源事件；同 body 去重；
- 助手消息不提取（避免把助手的话写成用户事实）。

## 影响面

- 纯新增模块，**未接 MCP 工具**、未调用任何模型；规则提取仍是默认路径。
- 未来接入只需实现 `call_model` 并决定触发时机（轮次结束/后台任务）。
