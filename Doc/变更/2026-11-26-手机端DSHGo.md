# 2026-11-26 手机端接入 dshgo

## 时间

2026-11-26 16:00–16:40（Asia/Shanghai）

## 原因

主人要在手机上用 DSH，选定社区方案 DSH Go（dshgo）：
一个安卓 App + 一个把 `127.0.0.1` 上的 `dsh web` 暴露到局域网/自建隧道的 DSH 插件。

## 改动

### 补上运行前提

- 全局安装 DSH CLI：`npm i -g @deepseek-ai/dsh@latest` → 版本 `0.2.2-rc.5`，与桌面端同版本；
- 全局安装 pnpm（`dsh plugin` 转发给 pnpm，原来机器上没有）→ `12.23.0`。

### 插件

- `dsh plugin --profile web add @xiazhi88/dshgo -w` → `@xiazhi88/dshgo@2.0.5`；
- 装在 **web profile**（`C:\Users\XHLENOVO\.dsh\profiles\web`），不动 desktop profile；
- 插件在 3081 建立转发代理到 3080，改写 Host/Origin 为 loopback，注入 launch token 与两个 polyfill。

### 服务

- `dsh web --no-open`（工作目录 `D:\大肥鱼`）作为后台任务启动；
- 监听：`127.0.0.1:3080`（DSH 本体）+ `0.0.0.0:3081`（dshgo 转发）；
- 新增启动器 `D:\大肥鱼\Tools\启动手机端.cmd`。

### 手机端

- 下载 `dshgo-app.apk`（GitHub release `app-v4.4.3`，2,337,405 bytes，包名 `com.dshgo.app`）；
- 生成局域网二维码 `dshgo-qr.png`，内容 `http://10.39.19.235:3081/`。

## 影响面

- 只在 web profile 生效；桌面端（desktop profile）未被修改；
- 新增两个全局 npm 包（`@deepseek-ai/dsh`、`pnpm`）；
- 新增一个对外监听端口 3081，**当前未设访问密码**，同一网络内任何设备可打开。

## 验证

- `http://127.0.0.1:3081/__dshgo__/info` → 200，`listening: true`，`version/ latestVersion` 均 2.0.5，`updateAvailable: false`；
- 同一端点经 `http://10.39.19.235:3081/__dshgo__/info` 也能 200，说明转发在 WLAN 网卡上可达；
- 裸地址 `http://10.39.19.235:3081/` 带浏览器 Accept 头 → 303 跳转，插件确实注入了 launch token；
- 带 token 的地址 → 200（42,195 bytes 的 index），并下发 `dsh-auth-*` cookie，随后裸根路径 200；
- APK 校验：zip 结构完整，483 个条目，`classes.dex`，`AndroidManifest.xml` 含 `com.dshgo.app`、`ApprovalReceiver`、`WatchService`。

## 限制

- **手机和电脑不是同一个 DSH**：手机连的是 web profile，独立会话库。桌面上的人设（soul-md）、记忆（dafeiyu-memory）、宠物、心情、语音、刷流插件都不在 web profile 里；
- 模型凭据不跨 profile，手机端第一次用可能需要重新登录/填 key；
- launch token 每次 `dsh web` 启动都会变，二维码指向裸地址（依赖插件注入），不要收藏带 token 的 URL；
- `dsh web` 是会话里的后台进程，关掉这个会话/启动器窗口服务就停；
- **校园网（gdut，10.39.19.0/19）可能有客户端隔离**，手机能否直连未实测；
- 3081 没有访问密码，同网段任何人都能打开这台电脑的 DSH（等于任意命令执行）；出门在外不要直接暴露该端口，用 Tailscale 之类；
- dshgo 是第三方项目（MIT），不是 DeepSeek 官方客户端。

## 回滚

1. 停掉 `dsh web` 进程（关启动器窗口，或结束 `E:\nodejs\node.exe` 里对应 PID）；
2. `dsh plugin --profile web remove @xiazhi88/dshgo`；
3. 需要时 `npm rm -g @deepseek-ai/dsh pnpm`；
4. web profile 里的会话数据在 `~/.dsh/profiles/web`，可整体备份后删除。
