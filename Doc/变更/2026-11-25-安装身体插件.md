## 验证证据

- `profiles/desktop/package.json` 的 `dsh.profile.bundles` 已包含 `dsh-soul-md`、`dsh-pet`。
- `dsh-soul-md`：本次会话工具列表出现 `soul_read`、`soul_update`、`memory_*`；`soul_read` 返回「No persona card is active」，说明宿主半端正常工作、尚未建卡。

## 回滚

```powershell
dsh plugin --profile desktop remove dsh-pet
dsh plugin --profile desktop remove dsh-soul-md
```

或从 `profiles/desktop/package.json` 的 `bundles` 与 `dependencies` 中移除后重启。删除 `~/.dsh/dsh-pet` 可清理宠物状态。
